第1話人物Profile

From interface to infrastructure.

I build the front of products in React, Next.js and React Native, and the services behind them in Node.js, Python and Java on PostgreSQL, Supabase or Firebase. On the platform side I write Terraform for AWS and build internal tools that keep deployments secure and auditable.

Much of my recent work puts AI to work, from assistants and agents to MCP servers, built so their answers trace back to real data. Many of my projects are designed for South Africa: POPIA, low-data Android phones, people who pay with cash or USSD, and load-shedding.

流儀How I build

  • Evidence over invention

    ApplyAI won’t write a CV line it can’t trace to a real fact. The WeServa chatbot answers only from real search results, and the product finder tags every figure as verified, estimated or unverified.

  • Secure by default

    Nothing the Terraform MCP server deploys is publicly reachable. The EC2 sandbox has no open ports, the tag gate fails closed, and Silent Vault signs the exact amount of every payment.

  • Built for South Africa

    TollPass SA takes USSD and retail-voucher top-ups for people without smartphones or bank cards. Project Ubuntu targets low-data Android phones, and ChargeRescue plans for load-shedding.
